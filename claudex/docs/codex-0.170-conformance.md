# Codex app-server 0.166.0 to 0.170.0

Claudex vendors the experimental 0.170.0 schema generated by the release
binary. Native Codex requests and the native initialize response continue to use
the configured Codex app-server. The standalone facade advertises 0.170.0 and
serves the subset listed in [COMPATIBILITY.md](../COMPATIBILITY.md).

| Wire change | Claudex behavior |
| --- | --- |
| `model/list.modelProvider` | The router sends explicit Claude and local ACP queries to their facades, serves `claudex-local` from the configured self-hosted catalog, and forwards other explicit queries to native Codex. The default query combines the available catalogs. A scoped ACP catalog marks the configured primary model as default when present. |
| `Thread.attachedToThreadId`, `includeAttachedThreads` | Stored side chats report their parent. An opted-in search includes them. The router emits the upstream result shape for merged searches. Listing side chats by parent still works. |
| `thread/list.currentAccountOnly` | Native Codex applies its login filter to native threads. Facade history has no ChatGPT login scope. |
| `thread/section/changed` | The facade broadcasts after a successful section move, including reordering or leaving a section. |
| `account/securitySetup/read`, `modelProvider/list`, `modelProvider/config/write` | The router forwards these to native Codex. |
| `thread/guardianReview`, `thread/prepareApprovedPlan` | Native Codex serves its own threads. The facade does not implement these workflows. |
| `requiredHumanApproval`, environment selection, deferred item output, in-progress sample and interrupt overrides | These options are implemented by native Codex. The facade retains its existing Claude approval, workspace, item paging, and settled-turn sampling behavior. |
| Other added optional metadata and enum variants | Native Codex supplies its own payloads. Facade messages continue to validate against the updated schema. |

The router preserves native model tiers and per-turn overrides, including
`ultrafast`. Claude model entries advertise their backend's own Fast capability.
For the prior changes, see the [0.166 conformance checklist](codex-0.166-conformance.md).
